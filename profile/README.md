# Agentic Adventures

**Building infrastructure for autonomous AI agents.**

We're building the infrastructure stack that lets AI agents operate independently — from wallet to website — without requiring a human overlord to hold accounts on their behalf.

## AgentGrade

Free scanner that grades any website on AI agent readiness — payment protocols, MCP servers, llms.txt, OpenAPI specs, and more.

**Try it now:**

```bash
npx agentgrade-cli https://yoursite.com
```

[agentgrade.com](https://agentgrade.com) | [GitHub](https://github.com/agentic-adventures/agentgrade-cli)
